# Changelog

## [0.1.0] — 2026-10-11
First release.
- **Mark with TExporT** in the long-press text menu of every app (Android `PROCESS_TEXT`), plus **Share → TExporT** for whole conversations.
- Mark sheet with source app, size, optional note and collection picker.
- Collections: list markers, edit notes, delete or copy markers, rename, delete.
- Export the handoff as text to any app, or save it as `.md`. The output is identical to the TExporT browser extension's.
- First-run setup with **I also use the TExporT browser extension**, plus `.texport.json` send and import for moving collections between phone and browser.
- No permissions, no network access.
